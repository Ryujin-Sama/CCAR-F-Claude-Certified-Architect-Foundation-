## 📌 Overview

This repository contains practical code examples, agent implementations, and API health-check tools designed to prepare for the **Claude Certified Architect Foundation (CCAR-F)** exam. It covers hands-on integration with the **Anthropic Claude API**, tool-use patterns, and building autonomous agents.

---

## 📂 Repository Contents

*   **`agent.py`**: Core Python script implementing autonomous AI agent workflows powered by Claude.
*   **`api_check.py`**: Utility script to verify Anthropic API key connectivity, model availability, and latency.
*   **`.env`**: Local environment configuration file storing API credentials (*git-ignored for security*).
*   **`LICENSE`**: MIT License.
